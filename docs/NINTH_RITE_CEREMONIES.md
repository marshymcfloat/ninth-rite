# Ceremonies and motion · 22 October 2026

Presentation-only update using the installed GSAP/PixiJS libraries and existing seven rite illustrations. No additional assets generated or credits spent.

## Event flow

- Natural entry: three or more visible scatters illuminate in sequence, draw energy into the halo, then the awarded rite opens as a full-screen ceremony after the base cascade chain.
- Purchased feature: existing symbols first fall away; a non-paying entry board tumbles in with exactly three scatters for Lesser, four for Blood, or five for Greater. The scatters activate before the recorded featureStart event opens “The rite is ready.” God Mode lands one enlarged entity scatter before its guaranteed intervention. Merely selecting a rite still spends nothing. The Spin action settles the existing server result before playback.
- Bonus introduction: veil fade, opening gate panels, halo reveal, staggered title/spin count/rules, then “Enter the rite.” The exact number of spins and starting altar come from the event book. God Mode shows one ritual spin and its recorded pre-spin altar.
- Retrigger: scatter activation followed by the recorded +5 award and remaining spins.
- Cascades: local payout label, total-win response, blood and Offering readout reactions. Existing liquid dissolution and streams remain in place.
- Round finish: count-up to the recorded payout. Greater than the round cost uses “You won”; 20× base bet or above additionally uses “A grand offering.” These are presentation thresholds only. Zero or non-profitable returns use neutral wording and no win sound. Feature summaries wait for Continue; base results also close automatically after a brief hold.

Replay and scripted examples explicitly identify themselves and say the balance is unchanged. Summaries label the figure as total returned, show the actual round cost, and never imply that a return below the cost is profit.

## Motion and interaction

Existing artwork is framed by moving ring ornament, slow embers, and a crimson veil. Controls react to hover/press; the resolving Spin icon rotates; selector art moves slightly on hover. The frame gently changes illumination. The priest has stronger restrained breathing and a brief bow during invocation; Offering marks glow; board cells illuminate on hover. These remain layered illustrations, not skeletal character animation.

No bounces, squash/stretch, near-miss inventions, or outcome-dependent client randomness. No game engine, configuration, scenario, probability, payout, or settlement changes.

Purchase entry boards are isolated presentation data based on the quiet layout. They contain no paying clusters or Offering marks, never enter the engine, never consume a free spin, and never add a request or charge. The first recorded bonus board replaces the entry board completely. Purchased-round replay includes the entrance; instant refresh recovery bypasses it. Scripted demonstrations and naturally earned bonuses keep their original boards. The basic display also highlights entry scatters and enlarges the God entity.

## Playback controls

First Continue/Escape during entrance completes its reveal; the next continues playback. Skip remaining playback is available inside the modal. Native dialog focus traps background controls; focus returns to Spin after completion. Fast mode compresses introductions; reduced motion presents complete static information, retaining Continue. Hidden tabs finish active presentation work. Refresh restores the settled result immediately without replaying an entrance. Missing GSAP retains static overlay controls.

The controller owns all entrance/exit timelines and timers and resolves pending presentation promises when skipped or destroyed. A queued close event from an earlier overlay cannot dismiss the next overlay.
